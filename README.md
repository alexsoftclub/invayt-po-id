# Инвайт по ID в Telegram: приглашение людей без юзернейма

Инвайт по ID - это приглашение человека в группу по его числовому ID, без поиска по юзернейму. Так можно позвать даже тех, у кого юзернейма нет вовсе. В **AlexSoftClub** инвайт по ID встроен в задачу **17 Инвайтер** и готовится задачей **4 Парсер пользователей**: аккаунт один раз просматривает чат-источник, запоминает ключи доступа к людям, а потом приглашает их одним запросом на человека.

## Как это работает

Telegram принимает приглашение по ID только от аккаунта, который сам видел этого человека в чате: у каждого аккаунта свой ключ доступа на каждого человека. Поэтому каждый аккаунт, который будет приглашать, должен один раз пройти чат-источник парсером. Ключи хранятся в служебной таблице `04 3 Парсер хеши для инвайта`, вручную её не редактируют.

1. **Сбор людей с ID.** В парсере ставите "Сохранять пользователей без юзернейма" = `1`, вписываете чат в `04 1` и парсите его. В `04 2` появляются строки с "ID пользователя" и пустым юзернеймом.
2. **Список для инвайта.** Переносите нужных людей в `17 1`: колонки "✅ Юзернейм" и "✅ ID пользователя", одна из двух или обе.
3. **Подготовка аккаунтов.** Ставите "Парсить только людей из списка Инвайтера" = `1`, выбираете аккаунты для инвайта и запускаете парсер. Каждый вступает в чат и ищет только людей из `17 1`. В консоли видно, например: `найдено 236 из 240`. Если список участников скрыт, аккаунт сам переключится на авторов сообщений.
4. **Инвайт.** Возвращаете настройку в `2` и запускаете Инвайтер как обычно.

## Возможности: как Инвайтер выбирает способ

Отдельной настройки нет, решение принимается по каждой строке `17 1`:

| В строке | Ключ у аккаунта | Что происходит |
|----------|-----------------|----------------|
| ID, с юзернеймом или без | Есть | Приглашение по ID, без резолва |
| Юзернейм, ID пустой или ключа нет | - | Обычный путь: резолв юзернейма, затем приглашение |
| Только ID | Нет | Строку берёт другой аккаунт, у которого ключ есть |

Лимит на чужие строки не тратится, в `17 4` при инвайте по ID вместо юзернейма стоит ID. Строки с ID берут и режимы [инвайтинга админами](https://github.com/alexsoftclub/invayting-adminami), а базовый и быстрый режимы описаны в [инвайтинге в Telegram](https://github.com/alexsoftclub/invayting-telegram).

## Лимиты Telegram: почему ID бережнее

- По юзернейму на человека уходит два запроса: резолв и приглашение. По ID - один. За круг в 30 человек это 60 запросов против 30.
- У резолва незнакомых юзернеймов свой суточный лимит - около **200 на аккаунт**, дальше ошибки и ожидание на часы. По юзернейму аккаунт не сделает больше 200 инвайтов в сутки, даже если лимит приглашений позволяет.
- Подготовка не резолвит людей по одному: аккаунт листает участников или сообщения страницами по 200. 10 000 человек - около 50 запросов на аккаунт.

## Как запустить

1. Мышкой кликните **4 Парсер пользователей**, поставьте "Сохранять пользователей без юзернейма" = `1`, нажмите **"Продолжить"** и **"Запустить"**.
2. Перенесите людей в `17 1`.
3. Снова запустите **4 Парсер пользователей** с "Парсить только людей из списка Инвайтера" = `1` на аккаунтах для инвайта.
4. Верните настройку в `2`, кликните **17 Инвайтер**, в подменю - **Инвайтер**, затем **"Продолжить"** и **"Запустить"**.

## Частые вопросы

### Как пригласить в группу Telegram человека без юзернейма?
По ID. Сначала аккаунт, который будет приглашать, проходит чат, где состоит этот человек, парсером AlexSoftClub в режиме "Парсить только людей из списка Инвайтера". После этого Инвайтер добавляет человека по ID одним запросом.

### Почему аккаунт не берёт строки с ID?
У него нет ключа доступа к этим людям - подготовку через парсер не делали. В консоли при старте видна строка с числом строк "без хеша у этого аккаунта". Юзернеймы при этом приглашаются как обычно.

### Можно ли вписать ID вручную?
Да. Тогда при подготовке человека ищут во всех чатах из `04 1`, и найден будет только тот, кто в них состоит.

### Что будет, если человек вышел из чата после первого парсинга?
Другие аккаунты его уже не найдут и ключа не получат. Такую строку аккаунт без ключа не берёт, и она остаётся необработанной.
